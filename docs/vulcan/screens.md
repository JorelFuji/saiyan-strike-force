# Screen Inventory

1. **Onboarding** — 2–3 screens max: welcome, Health opt-in (skippable), done. No account. Do not request every Health permission at launch.
2. **Today (Home)** — today's scheduled workout(s), Start, week completed count / streak, "Start Freestyle Workout."
3. **Planner** — week (primary) / month (dots) toggle; tap a day to see/add workouts; copy-week action when it ships. See [features/planner.md](features/planner.md).
4. **Workouts (Templates list)** — searchable list, create-new FAB, duplicate/archive via overflow (not swipe-to-delete as the only path). See [features/templates.md](features/templates.md).
5. **Workout Builder** — name/notes, ordered exercise list, structured sets/reps/load/rest editor.
6. **Workout Detail (template, read view)** — preview; "Start" and "Edit."
7. **Active Session** — tap-first set log, compact exercise strip, non-modal rest timer, overflow for destructive actions. See [features/active-session.md](features/active-session.md).
8. **Session Summary** — recap vs. planned snapshot; per-provider Health sync state (`Not enabled` / `Permission needed` / `Pending` / `Synced` / `Failed`) with retry. Finish never blocks on this. See [features/health.md](features/health.md).
9. **History (list)** — grouped by date, filter bar. See [features/history.md](features/history.md).
10. **Session Detail** — full logged breakdown.
11. **Exercise Trend view** — last-time log lines first; optional simple volume/top-set stats. Not a chart suite.
12. **Settings** — units (kg/lb), theme (dark/light/system), Health toggles, rest-timer auto-start, data export, app info, app-lock. No accent picker in v1. See [features/privacy-export.md](features/privacy-export.md).
